# NextClass

**Следующая пара — в уведомлениях macOS.**

NextClass получает расписание из Sirius Schedule API и показывает ближайшее занятие для выбранной учебной группы. При первом запуске открывается системное окно выбора группы; последующие запуски используют сохранённые настройки.

Проект реализован на **JavaScript for Automation (JXA)** с использованием встроенных средств macOS. Для работы не нужны Python, Node.js, Homebrew или сторонние библиотеки.

## Возможности

- Выбор группы из актуального списка API при первом запуске.
- Сохранение группы и возможность изменить её позже.
- Системные уведомления с предметом, аудиторией, преподавателем, датой и временем.
- Поиск ближайшей пары среди опубликованных занятий, включая последующие дни.
- Расчёт времени по Москве (UTC+3), независимо от часового пояса компьютера.
- Удаление дубликатов и отдельные уведомления для параллельных занятий подгрупп.
- Обработка сетевых ошибок, некорректного ответа API и отсутствия будущих занятий.
- Вывод полного результата в Терминал.

## Требования

- macOS с доступными `/usr/bin/osascript` и `/usr/bin/curl`.
- Активная графическая сессия пользователя для окон и уведомлений.
- Доступ к интернету и сервису расписания.
- Разрешённые системные уведомления для приложения, запускающего скрипт.

## Быстрый старт

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его.
2. Откройте Терминал в папке с файлами проекта.
3. Выполните:

```sh
bash NextClass.command
```

При первом запуске выберите свою группу в появившемся списке. Скрипт сохранит выбор, получит расписание и отправит уведомление.

Для повторной проверки выполните ту же команду.

### Запуск двойным нажатием

Если файлы не имеют права на выполнение, один раз выполните в папке проекта:

```sh
chmod +x NextClass.command Choose-Group.command
```

После этого `NextClass.command` можно открывать из Finder двойным нажатием. Все файлы проекта должны оставаться в одной папке.

### Смена группы

```sh
bash Choose-Group.command
```

Или:

```sh
bash NextClass.command --choose-group
```

После выбора новой группы скрипт сразу проверит её расписание. Отмена выбора оставляет прежние настройки.

### Прямой запуск JXA

```sh
osascript -l JavaScript nextclass.js
osascript -l JavaScript nextclass.js --choose-group
```

## Пример уведомления

Ниже — условный пример содержимого, а не скриншот реального расписания:

> **Следующая пара**  
> К0409-23 · 26.10.2026 · 08:30–09:50 МСК  
> Информационная безопасность  
> Аудитория: 101  
> Иванов Иван Иванович

Для онлайн-занятий добавляется пометка «Онлайн». Если предмет или аудитория не указаны в API, уведомление сообщает об этом.

## Как это работает

1. Скрипт читает сохранённую группу. Если настройки отсутствуют или повреждены, запрашивает список групп и открывает окно выбора.
2. Получает расписание начиная с текущей московской даты, учитывая пагинацию API.
3. Проверяет точное совпадение группы по полю `target`, корректность дат и времени.
4. Исключает прошедшие начала занятий, удаляет дубликаты и сортирует записи по времени.
5. Показывает уведомления для всех занятий с ближайшим временем начала.

**Следующая пара** — занятие, начало которого ещё не прошло. Уже идущая пара пропускается. Если сегодняшние пары закончились, поиск продолжается по последующим датам, доступным в API. В точный момент начала занятие также может попасть в результат.

Если будущих занятий нет, выводится сообщение «Будущих занятий нет в опубликованном расписании». Оно означает отсутствие записей в API и не гарантирует отсутствие занятий.

## Настройки

Группа хранится локально, вне папки репозитория:

```text
~/Library/Application Support/NextClass/config.json
```

Пример содержимого:

```json
{
  "group": "К0409-23"
}
```

Удаление этого файла сбросит выбор группы. Для обычной смены группы рекомендуется использовать `Choose-Group.command`.

В текущей реализации API не требует токена. Выбранная группа передаётся сервису расписания как параметр запроса. Кэш расписания не создаётся.

## Используемый API

Источник данных: [Sirius Schedule API](https://sirinium.avh-vless.work/).  
Документация сервиса: [Swagger UI](https://sirinium.avh-vless.work/docs).

| Метод | Endpoint | Назначение |
| --- | --- | --- |
| GET | `/api/groups` | Получение массива названий учебных групп |
| GET | `/api/schedule` | Получение массива занятий с фильтрами и пагинацией |

Параметры запроса расписания:

| Параметр | Значение |
| --- | --- |
| `section_type` | `group` |
| `group` | Название выбранной группы |
| `date_from` | Текущая дата по Москве, `DD.MM.YYYY` |
| `limit` | `2000` записей на страницу |
| `offset` | Смещение для последовательного получения страниц |

Адрес сервиса задан константой `API` в `nextclass.js`. NextClass является клиентом сервиса; сам сервер расписания в репозиторий не входит.

## Проверка логики

Для разработки можно использовать Node.js. Он нужен только для запуска тестов, а не для работы NextClass на macOS.

```sh
node test.js
```

Тесты используют встроенный модуль `assert` без установки npm-пакетов. Они проверяют выбор будущих занятий, точное совпадение группы, удаление дублей, сохранение параллельных занятий, московскую дату, некорректные даты и время, переход через выходные и пустое расписание.

Успешный результат:

```text
8 checks passed
```

Тесты не обращаются к API и не отправляют уведомления. Они не проверяют системные окна, сохранение настроек и доставку уведомлений — эти сценарии требуют запуска на Mac.

## Устранение неполадок

| Проблема | Что проверить |
| --- | --- |
| Уведомления не видны | Разрешения в «Системные настройки → Уведомления» и режим «Фокусирование». Отправитель может отображаться как Script Editor / «Редактор скриптов» в зависимости от способа запуска и версии macOS. |
| Файл не запускается двойным нажатием | Запустите `bash NextClass.command` из Терминала или добавьте право на выполнение через `chmod +x`. |
| macOS блокирует загруженный файл | Проверьте исходный код и используйте штатное подтверждение открытия в настройках безопасности, если доверяете файлу. |
| Ошибка соединения | Проверьте интернет и доступность сайта API. Таймаут подключения — 10 секунд, одного запроса — 30 секунд. |
| Предмет не помещается в баннер | macOS может сокращать длинный текст; полный результат доступен в Терминале. |
| Группы нет в списке | Список поступает из API; проверьте наличие группы у источника расписания. |
| В расписании нет корректной даты или времени | Скрипт сообщает об ошибке вместо ненадёжного выбора пары. Проверьте данные у источника. |

## Ограничения и статус проверки

- Один запуск выполняет одну проверку. Фоновый мониторинг, таймер и автозапуск не устанавливаются.
- Работа зависит от доступности API и актуальности опубликованного расписания.
- Отдельного выбора подгруппы нет: занятия с одинаковым ближайшим временем показываются отдельными уведомлениями.
- Часовой пояс расписания задан как UTC+3.
- Схема API и реальные ответы проверены 22 октября 2026 года; автоматические проверки логики пройдены.
- Окно выбора, сохранение настроек и доставка уведомлений на macOS пока не проверены. Минимальная поддерживаемая версия macOS не установлена испытаниями.
